# 1. Power Manager Program
A mini-project about power manager program by C. This project will simulate a system can manage 20-30 devices in smart home. The system will track the power consumption, state of devices and automatically adjust when threshold is over.
# 2. Features
1. Manage and simulate system.
2. Read the config of devices from txt file.
3. Automatically turn on/off or change mode of devices based on battery level, priority or essential devices.
4. Add/delete device.
5. Write to log file the important event: on/off device; change mode; alert error or dangerous battery level.
6. Caculate time running.
7. Caculate total power consumption.
8. Total number of alerting.
# 3. Data Structure Algorithms
Using Linked List to manage devices
# 4. Input Format
The system will read the config information from txt file. Example:
{"id":"1","type":"quat","consume":300.0,"priority":1,"essential":0,"status":"off"}
