# 1. Power Manager Program
A mini-project about power manager program by C. This project will simulate a system can manage 20-30 devices in smart home. The system will track the power consumption, state of devices and automatically adjust when threshold is over.
# 2. Features
1. Manage and simulate devices
2. Read the config from file text
3. Automatically turn on/off or change mode of devices based on battery level and priority.
4. Write to log file the important event: on/off device; change mode; alert error or dangerous battery level.
5. Caculate time running
6. Caculate total power consumption
7. Total number of alerting
